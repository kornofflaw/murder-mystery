Murder Mystery · photo pass

Crime scene photo prompts

32 rooms across the four cases. Each scene names every object you can click in that room, so the pictures must show them all. Pictures go into a Google Drive folder called Murder Mystery Photos, and Claude takes them from there.

All 32 in one go

  1. Copy the all-in-one prompt

    Paste it into a new ChatGPT chat. Turn on Google Drive in ChatGPT first if it asks.

  2. Keep it going

    ChatGPT may stop after a few pictures. Type continue and it picks up at the next one.

  3. Check each picture

    Every item in its “Must show” list should be visible. If one is missing, say which and ask it to redo that picture.

  4. Tell Claude

    When a batch is in the Drive folder, tell Claude. Claude marks the click areas and switches those rooms to photos.
